### 🚀 Featured Engineering Projects

#### 1. [AI Commerce Marketplace Platform](https://github.com/tienchinh21/ai-commerce-marketplace-platform)
*Enterprise AI-powered Commerce Marketplace Platform with Semantic Product Search, Review Intelligence & Guarded Text-to-SQL Analyst.*
- **Admin CMS:** Built with React 19, Vite, Ant Design 5, React Query, and Zustand with reusable table/form components and role-based permissions.
- **Core Marketplace APIs:** Implemented in NestJS 11 with TypeORM and PostgreSQL 16.
- **AI Intelligence Services:** Natural language product discovery powered by `pgvector` embeddings & cosine similarity, automated review sentiment clustering, and safe read-only Text-to-SQL analyst workflows.

#### 2. [Mini Banking Ledger & Payment Gateway](https://github.com/tienchinh21/mini-banking-payment-gateway)
*Fintech banking ledger and merchant payment gateway modeling money consistency and high-reliability transaction flows.*
- **Core Ledger Design:** Double-entry journal accounting, wallet balance projections, and PostgreSQL row-level locking for concurrent debit operations.
- **Merchant Gateway:** Idempotency key deduplication, HMAC-SHA256 request signature verification, and transactional outbox webhook dispatch.
- **Admin Backoffice CMS:** React 19, TypeScript, Ant Design 5, and TanStack Query for account management, transaction inspection, and audit trails.

#### 3. [Interactive Developer Portfolio](https://github.com/tienchinh21/portfolio)
*Modern interactive developer portfolio showcasing work, capabilities, and personality with a cyberpunk aesthetic.*
- **Stack:** Next.js 15 (App Router), React 19, Tailwind CSS v4, Prisma ORM, Better Auth, WebGL particle effects, and Framer Motion.
- **Features:** Interactive terminal CLI simulator, custom sound FX, dynamic theme switcher, and full English / Vietnamese bilingual support (i18n).

### 🛠️ Engineering Principles

- **Data Integrity & Consistency First:** Prioritize transaction safety, schema normalization, and idempotency over quick hacks.
- **Strict Type Safety:** Leverage TypeScript across both client and server to catch contract mismatches at compile time.
- **Disciplined AI Utilization:** Use AI coding agents (ChatGPT, Claude, Codex) to accelerate prototyping and refactoring, backed by strict manual code review and test validation.
- **Clean Architecture:** Maintain clear boundaries between Domain logic, Application services, and Infrastructure adapters.
